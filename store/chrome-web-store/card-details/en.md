## Detailed description

```
OpenKey for the browser fills logins, passkeys, payment cards, and secrets from the same encrypted vault as the OpenKey app. Unlock with your master password in standalone mode (ciphertext can sync from a self-hosted OpenKey Server), or use native messaging when the desktop app is already unlocked.

Autofill uses content-script overlays, the context menu, and a keyboard shortcut. Save or update a login from the page. Passkeys intercept WebAuthn create and get while the extension is unlocked. Browse cards, crypto wallet labels, and developer secrets; fill card forms and token fields; copy a wallet address. Attachments can be listed and downloaded in standalone mode. Shares and organizations follow the vault you unlocked.

Nothing in the page is sent to OpenSelfHosting as plaintext. Keep the extension locked when you leave the machine.

Privacy policy: https://openselfhosting.com/privacy
Terms: https://openselfhosting.com/terms
Website: https://openselfhosting.com
Support: security@openselfhosting.com

FAQ — browser password manager, passkeys, native bridge
Does the extension work without the desktop app? Yes. Standalone mode unlocks the vault in the browser.
Can it talk to the OpenKey desktop app? Yes, via native messaging when that app is unlocked.
Are passkeys supported? Yes, WebAuthn create and get while the extension is unlocked.
Is this a cloud password manager? Optional self-hosted sync stores ciphertext only.
```
